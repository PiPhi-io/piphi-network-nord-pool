# Nord Pool price widget

Read-only Widget SDK card for the configured Nord Pool market area. It displays
only the current and next interval prices already published by the integration.
No host network access or command permission is requested.

Run `npm test`, `npm run build`, `npm run validate`, and `npm run conformance`
before packing. Preview SVGs are illustrative; runtime state is the source of
truth. A full-day chart remains planned until interval data is an implemented
runtime capability.
